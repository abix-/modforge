# abioticfactor-mod open issues

Goal: play on Hard with scaled rewards, raise max skill level from 20 to 100.

Second goal: an AI player. A second player character that lives in the same world by the same rules as the human player, driven by the shared bot through player input. The game places it where it places any joining co-op player. It knows the map layout and the navigation mesh, but learns container contents and enemies only when it sees them. Near the human it walks with player input and obeys every rule. Far from the human it steps along a path the mesh returned, without physics, and never through a door it cannot open or a gap with no link. Operator decision 2026-09-12: the AI player has no restrictions beyond what breaks the game. Every action the human player can take, the AI player can take, story triggers included. When it dies it respawns by the game's own rules, and a bed it sleeps in moves its respawn point like anyone else's. It levels its own skills by doing things, so finding it grinding enemies is expected, not a bug. Operator direction 2026-09-12: the AI player joins the running game as another co-op player, and the mod takes it over. The human player is never driven by the mod. The first shipped state is one AI player that walks to a container and takes an item.

Layering, same as the bot-navigation doc: modforge owns the one AI player system (the view of the world, the need-based goal picker, the step loop, the event log and memory, far mode, respawn handling, link generation) so it can run in many games. Ueforge and Unityforge connect it to their engines (second player body, per-player input, observing any character, path requests, mesh edges, nearby things). This crate supplies only this game's data (class names, key names, need fields, the PDB path) and the live proofs. Shared rows live in the workspace `docs/todo.md`.

Status 2026-09-12: only the reads marked "Live" below have run against the game. Nothing has moved a character in this game, no second player has been created, no AI player code exists in modforge or here, and this mod has no function-call op yet.
